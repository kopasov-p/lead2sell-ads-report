Как считаются показатели

  • Посещения — уникальные клики с gclid (Google) или fbclid (Facebook), которые дошли до сайта (рекламный трекер бэкенда). Метрика видит их не все: она срабатывает только после согласия на cookie.
  • Заявки — оставили контакт на лендинге (анкеты и чат-формы). Повторные заявки с того же телефона за период не считаются.
  • Атрибуция — по последнему клику. Касание — заявка или регистрация с метками источника. БК, монетизация и оплаты относятся к последнему касанию перед ними; если после него была заявка из другого источника — уже не к нам. Старые клиенты считаются тоже: если клиент был в базе давно, но вернулся через рекламу, его заявка, БК и оплаты засчитываются этой рекламе.
  • Записались на БК — клиенты с заказом бесплатной консультации, который не был отменён (всё, кроме ABORTED; неудачные дозвоны остаются).
  • Пришли на БК — консультация состоялась: звонок выполнен, бесплатный, от 90 секунд. Бонусные звонки от эксперта и бонусные минуты не считаются.
  • Монетизация — первый платёж клиента свыше 100 ₽ после рекламного касания, даже если раньше клиент уже платил. Доход — все оплаты клиента, которые по последнему клику относятся к этой рекламе.
  • CPL = расход / заявки, стоимость БК = расход / пришли на БК (как ЦБАК в Директе), CAC = расход / монетизации. Прочерк — расход на этом уровне неизвестен или событий не было.
  • ROAS = доход / расход × 100%, как ROAS строгий в отчёте по Яндекс.Директу.
  • Каждое событие считается по своей дате: заявка — по дате заявки, БК — по дате заказа, оплата — по дате платежа.
  • Сайт теряет метки, если человек ушёл с посадочной вглубь сайта, — регистрация тогда записывается как «прямой заход». Поэтому касание ищется ещё в двух местах: клики рекламного трекера, привязанные к клиенту, и ранние визиты клиента с метками в Яндекс.Метрике (по его ID Метрики; Метрика хранит только дату визита).
  • Метки источника: Google — partner=GoogleAds или gclid, Facebook — partner=fbinst или fbclid. Тестовые и фейковые аккаунты исключены, если уже размечены (разметка обновляется раз в сутки).
  • Google: кампании без UTM-меток показаны по ID кампании, разбивки по объявлениям и ключам у них нет; у КМС-кампаний в utm_term приходит площадка, а не ключевое слово. Facebook: utm_campaign — ID кампании, utm_term — ID группы объявлений, utm_content — ID объявления; клики без меток собраны в строку «Без UTM-меток».
  • Расход, показы, клики — из кабинета: Google — API или выгрузка, Facebook — выгрузка из Ads Manager. Валюта кабинета пересчитывается в рубли по курсу ЦБ на дату расхода.
